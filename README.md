# Análisis de ventas

Proyecto de práctica para explorar datos de ventas ficticias y responder preguntas de negocio.

## Objetivo

Analizar qué productos y categorías generan más ingresos y observar las ventas por mes.

## Datos

El archivo `ventas.csv` contiene una muestra ficticia con fechas, productos, categorías, unidades y precios unitarios.

## Estado del proyecto

En desarrollo. El siguiente paso es importar los datos a una hoja de cálculo, calcular los ingresos y crear un resumen de resultados.

## Herramientas previstas

- GitHub para documentar el proyecto.
- Google Sheets o Excel para el análisis.
